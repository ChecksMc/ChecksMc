# Hi, I'm ChecksMc 👋

I'm a student in Bavaria who likes exploring ideas by building things and writing about them. I'm interested in computer science, mathematics and languages, as well as games as a way to express emotions and ideas.

## What I'm working on

- [**Cornernote for Fedora KDE**](https://github.com/ChecksMc/Cornernote-for-Fedora-KDE) — a Python and GTK quick-note overlay for Wayland that creates or appends Markdown notes for use with Obsidian.
- [**Portfolio**](https://github.com/ChecksMc/ChecksMc.github.io) — a lightweight static site, written in HTML, CSS and JavaScript, with translations in English, German, Chinese and French. It also contains my papers, including documentation for a task from the 44th Bundeswettbewerb Informatik, there are some issues with the pdf that will be fixed in the near future.
- **Other work** — I'm taking part in the 45th Bundeswettbewerb Informatik, working on my school [W-Seminar](https://github.com/ChecksMc/W-Seminar) and developing a game in Unity.
